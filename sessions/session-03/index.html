Sesión 03: Arte generativo con random(), noise() y semillas

Sesión centrada en crear un lienzo artístico estático con reglas visuales reproducibles. Se introducen random(), noise(), el control de semillas y el uso de lerp() para transiciones suaves.

Objetivos

  • Diseñar un sistema visual basado en reglas y variaciones.
  • Distinguir entre aleatoriedad pura (random()) y coherente (noise()).
  • Usar randomSeed() o noiseSeed() para reproducir resultados.
  • Aplicar lerp() para interpolar color, posición o tamaño.

Ideas clave

  • random() genera valores pseudoaleatorios. Con la misma semilla produce la misma secuencia.
  • noise() devuelve variaciones suaves útiles para texturas, ondas y flujos orgánicos.
  • lerp(a, b, t) mezcla dos valores y ayuda a suavizar transiciones visuales.

Actividad AC.01 — Cuadro generativo

Crea una pieza/cartel generativo a partir de un concepto visual, usando random() y/o noise(), patrones geométricos y semillas de aleatoriedad. Debes producir tres variaciones del mismo sistema, exportarlas y explicar las reglas visuales utilizadas.
