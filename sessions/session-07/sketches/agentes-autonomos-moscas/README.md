# Agentes autónomos y moscas

[Volver al tutorial de la sesión 07](../../index.html)

## Descripción

Sketch de aula inspirado en *The Nature of Code*. Un conjunto de agentes vuela
hacia la posición del ratón, representada con un emoji, y permite añadir nuevas
instancias con ratón o teclado para probar densidad, color y respuesta del
sistema.

## Qué practicar

- reconocer en la clase `Vehicle` las propiedades de posición, velocidad y
  aceleración;
- comparar cómo `seek()` modifica la trayectoria del enjambre;
- usar `mouseIsPressed` y las teclas `1` a `7` para introducir nuevas familias
  de color.
