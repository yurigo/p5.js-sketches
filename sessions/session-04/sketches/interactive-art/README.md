# Interactive art

[Volver al tutorial de la sesión 04](../../index.html)

## Descripción

Sketch que combina varias entradas del usuario en una sola composición: un clic
cambia el color, la rueda modifica el tamaño y la tecla `E` alterna entre
círculo y cuadrado. Mientras hay una tecla pulsada, el fondo deja de limpiarse y
permite acumular trazas visuales.

## Qué practicar

- coordinar `mouseClicked()`, `mouseWheel()` y `keyPressed()` en el mismo sketch;
- entender cómo una variable de estado cambia color, tamaño y figura;
- experimentar con `keyIsPressed` para pasar de una imagen efímera a otra acumulativa.
