# Composiciones con Strudel

Este ejemplo presenta dos patrones editables para ejecutar en el
[editor web de Strudel](https://strudel.cc/). El primero organiza percusión en
tres capas; el segundo añade una línea melódica. Copia un bloque de código en
el editor y pulsa reproducir. Los ejemplos y las instrucciones permanecen
disponibles en esta página sin cargar bibliotecas externas.

Consulta el [tutorial de la sesión 09](../../index.html) para los objetivos,
el recorrido académico y la práctica guiada.
