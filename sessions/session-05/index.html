Sesión 05: `dist()` y `map()`

Sesión dedicada a medir distancias y transformar rangos para convertir la posición del ratón en color, tamaño y cambios de luminosidad.

Objetivos

  • Usar dist() para calcular la cercanía entre el ratón y un objeto.
  • Usar map() para convertir coordenadas o distancias en otros valores.
  • Relacionar la posición del puntero con el color y el tamaño de una figura.
  • Diseñar respuestas visuales distintas según la proximidad del usuario.

Recorrido

  1. Empieza con raton-colorao para ver cómo mouseY puede convertirse en matiz y mouseX en diámetro mediante map().
  2. Observa que el círculo sigue al ratón y que una misma interacción puede controlar varios parámetros al mismo tiempo.
  3. Continúa con no-me-mires para introducir dist() entre el puntero y varias bolas distribuidas por el lienzo.
  4. Analiza cómo esa distancia se transforma otra vez con map() para producir cambios graduales de luminosidad.
  5. Compara ambos sketches para decidir cuándo te interesa mapear una coordenada directa y cuándo una distancia entre dos puntos.
