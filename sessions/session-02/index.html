Sesión 02: Formas, escenas y programación orientada a objetos

Recorrido guiado para consolidar figuras básicas, componer una escena completa, diseñar pixel art y encapsular dibujos en una clase.

Objetivos

  • Combinar figuras de p5.js para construir composiciones completas.
  • Organizar una ilustración por capas usando orden de dibujo.
  • Representar imágenes con una matriz de píxeles en texto.
  • Crear una clase Persona para reutilizar un dibujo.

Recorrido

  1. Revisa collision-ball para practicar movimiento, velocidad en ejes X/Y y rebote en los límites del lienzo.
  2. Analiza landscape para entender cómo superponer cielo, montañas, lago, casa y detalles con figuras primitivas.
  3. Explora pixel-art para transformar una matriz de caracteres en cuadrados de color con bucles anidados.
  4. Cierra con poo-persona, donde una clase modela una figura humana y permite dibujar muchas instancias.
