# Sistema de agentes

[Volver al tutorial de la sesión 06](../../index.html)

## Descripción

Sketch con agentes autónomos que recorren el lienzo, cambian de brillo según la
proximidad del ratón y dibujan líneas con los vecinos cercanos para formar una
constelación dinámica.

## Qué practicar

- leer un array de instancias de una misma clase;
- observar cómo `dist()` y `map()` afectan al brillo de cada agente;
- identificar qué método controla el movimiento continuo y las conexiones entre
  vecinos.
