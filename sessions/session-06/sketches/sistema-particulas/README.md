# Sistema de partículas

[Volver al tutorial de la sesión 06](../../index.html)

## Descripción

Sketch donde `draw()` funciona como emisor y va creando partículas desde el
centro del lienzo. Cada partícula reutiliza la idea de una `Ball`, pero añade
una propiedad `ttl` para desaparecer después de un tiempo.

## Qué practicar

- seguir el ciclo crear → actualizar → dibujar → destruir;
- entender cómo `ttl` controla la vida útil de cada partícula;
- comparar qué cambia entre una bola persistente y una partícula efímera.
