Sesión 08: sonido y DOM con p5.js

Una introducción a p5.sound y una comparación práctica entre manipular HTML con JavaScript nativo y hacerlo con las funciones DOM de p5.js.

  • Abrir ejemplo: DOM nativo
  • Abrir ejemplo: DOM con p5.js

Objetivos

  • Describir las posibilidades de p5.sound y consultar p5.Oscillator.
  • Distinguir la manipulación nativa del DOM de las funciones DOM de p5.js.
  • Responder a eventos del ratón modificando estilos y posiciones de HTML.
  • Crear, actualizar y eliminar elementos HTML desde un sketch sin canvas.
  • Proponer cómo conectar una interacción visual con un parámetro sonoro.

Recorrido

  1. Consulta la referencia de p5.Oscillator y piensa qué entrada podría controlar el sonido de una pieza generativa.
  2. Abre dom/ y sigue cómo querySelector() encuentra la bola y el evento mousemove modifica su posición con estilos CSS.
  3. Continúa con dom-with-p5js/. Observa que noCanvas() evita crear un canvas y que select() y createDiv() trabajan con elementos HTML.
  4. Sigue el ciclo de la fruta: aparición aleatoria, detección de proximidad, actualización del marcador y eliminación del elemento.
  5. Compara ambos ejemplos y decide cuándo te conviene usar las herramientas nativas del navegador o la abstracción de p5.js.

Ejemplos de la sesión

  • DOM nativo: mover un elemento con el ratón usando eventos y CSS
  • DOM con p5.js: recoger frutas con un sketch sin canvas

Exploración sonora

La sesión también presenta p5.sound y el oscilador como punto de partida para crear sonido o responder a entradas. Los dos ejemplos enlazados aquí se centran en el DOM y no implementan sonido; usa la referencia de p5.Oscillator para investigar una posible extensión sonora.
