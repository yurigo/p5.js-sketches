# DOM nativo

[Volver al tutorial de la sesión 08](../index.html)

## Descripción

Este ejemplo selecciona el elemento HTML `.bola` con JavaScript nativo y mueve
su posición cuando el ratón se desplaza por el documento. No crea un canvas ni
utiliza p5.js.

## Qué practicar

- encontrar un elemento HTML con `document.querySelector()`;
- escuchar el evento `mousemove` del documento;
- modificar las propiedades CSS `top` y `left` desde JavaScript;
- comparar el acceso nativo al DOM con las funciones de p5.js del otro ejemplo.

## Cómo abrirlo

Abre [index.html](index.html) en el navegador y mueve el ratón. Después,
consulta el [tutorial de la sesión 08](../index.html) para seguir la secuencia.
